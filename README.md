# Fuel Drivers Analysis

Analysing how the oil price and the rand exchange rate have moved together
since 2016, and what that means for South African fuel costs.

**Status:** in progress

## Data
Daily Brent crude (BZ=F) and USD/ZAR (ZAR=X) from Yahoo Finance via the
yfinance Python library, downloaded 25 October 2026.
